# The public-projection factory (generalized from the belief-log mirror)

> Status: canon-candidate · 2026-09-26 · branch `claude/projection-factory`
> WORLD.md §Field Geometry: "every projection factory is a lawful transform; the
> lossless invariants are what must survive every change of basis." This makes that
> law a reusable tool. PR #205 proved it once (belief log); this is the class.

## The contract (the minimal, whole thing)

A public projection is defined by exactly FOUR things, no more:

1. **source ledger** — an internal, append-only JSONL file. The SSOT ("one field").
2. **whitelist keys** — the ONLY keys copied into the served file. The sovereign
   zero: the change of basis that keeps only what may cross the air-gap.
3. **template** — a self-contained HTML file with a `/*DATA*/` marker where the
   whitelisted rows are injected as one JSON blob.
4. **the guarantee** — AIR-GAP BY CONSTRUCTION: internal prose is never in the
   whitelist, so it structurally cannot reach the served file (not by policy, by
   construction); and every embedded value is `<`-escaped so no value can break the
   `<script>`.

A projection is a PURE FUNCTION of (ledger, whitelist, template): same inputs render
byte-identical output. `--check` re-renders and compares without writing, so a stale
mirror fails CI instead of shipping. The invariant that survives every change of
basis: **the served file carries the SHAPE (cadence, counts, classes), never the
content.**

## The base — `scripts/projection_factory.py`

- `load(path, required_keys, id_key, date_key)` — JSONL loader, fails closed on bad
  JSON / missing key / malformed date / duplicate id. Accepts bare dates and full
  timestamps.
- `inject(template, rows, keys, marker, sort_keys, transforms)` — the lawful
  transform. Orders by `sort_keys` (need not be whitelisted), projects to `keys`
  only, applies optional per-key `transforms` (lossy coarsening toward shape, e.g. a
  full timestamp -> a date), `<`-escapes, injects at `marker`. A whitelisted key
  absent from a row embeds as `null`, never a crash, never a reach into a
  non-whitelisted key.
- `Projection` dataclass + `cli()` — a new instrument is one spec (see below) with
  `--check` (audit) and `--gate` (emit + run the three air-gap gates).
- `run_gates(target)` — runs the SAME three gates the belief log passes:
  `leak_check.sh` (whole-tree), `tripwire.sh`, `artifact_wrap_lint.py`.

## Adding a mirror (the whole emitter)

```python
import projection_factory as pf
P = pf.Projection(
    name="gauntlet log",
    ledger=pf.ROOT / "_STATE" / "gauntlet-runs.jsonl",
    template=pf.ROOT / "scripts" / "gauntlet_log_public_template.html",
    out=pf.ROOT / "public" / "gauntlet-log.html",
    required_keys={"run_id", "ts", "kind"},
    public_keys=("ts", "kind", "agents"),   # the air-gap: shape only
    id_key="run_id", sort_keys=("ts", "run_id"), marker="/*DATA*/",
    transforms={"ts": lambda v: str(v)[:10]},  # coarsen timestamp -> date
)
raise SystemExit(pf.cli(P))
```

Then add the route in `next.config.ts` in the house pattern: the specific rewrite
BEFORE the host catch-all, and extend the catch-all's negative-lookahead:

```
{ source: "/:path((?!.*beliefs|.*gauntlets).*)", destination: "/status.html", has: [{ type: "host", value: "status.arcs.care" }] },
```

## The worked example (the needle)

`_STATE/gauntlet-runs.jsonl` (adversarial pre-ship gauntlet runs) carries `subject`,
`finding`, `outcome`, and `counterpart` (real names live there, e.g. "Todd Hotes").
The mirror embeds only `(ts, kind, agents)` — cadence, class of pressure-test, and
fan-out size. Served at `status.arcs.care/gauntlets`. All three gates green on it.

## Gotchas learned building it

- **Tooling-provenance leak:** `leak_check.sh` bans the phrase `generated by` + a
  Python filename. A "GENERATED by <emitter>.py" banner in the template's CSS
  comment FAILS the gate (script filenames reveal the generator stack). Say
  "GENERATED, do not hand-edit" and name no Python file in the rendered surface.
- **The lede is not body text:** per WORLD.md the hero lede spans the full lane
  matching its heading. Do NOT cap it at a narrow reading measure. Letting the lede
  span the lane also keeps `artifact_wrap_lint` MODE 4/5 silent by construction (no
  `ch` cap, no container/measure mismatch).
- **Pre-existing state (2026-09-26):** whole-tree `leak_check.sh` is red on main from
  5 unrelated surfaces (blog-nftt "prior art"; three `*-war.html` recoil pages);
  `public/belief-log.html` fails `artifact_wrap_lint` (em-dashes + `62ch` caps). New
  surfaces here are clean under all three; those are separate pre-existing debts.
