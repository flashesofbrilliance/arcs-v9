## DRIFT FOUND

**`vercel.json` still rewrites `kelly-interview.arcs.care` root to the bare
static file `/kelly-interview.html`, not `/warroom/kelly-interview`.**

- Evidence: `vercel.json` (repo root) `rewrites` array:
  ```json
  { "source": "/", "has": [{ "type": "host", "value": "kelly-interview.arcs.care" }], "destination": "/kelly-interview.html" }
  ```
  `public/kelly-interview.html` no longer exists — confirmed via `ls` (No
  such file or directory). The file was moved to
  `runtime/warroom/kelly-interview.html` during the 2026-07-24 hardening,
  and `next.config.ts` was updated in that same pass to rewrite
  `kelly-interview.arcs.care` to `/warroom/kelly-interview` (the admin-gated
  route). `vercel.json` was last touched 2026-07-23 (commit `b8694a8`) — one
  day *before* the hardening commits (`acc2ee8`, `1e7bfa5`) — and was never
  updated to match.
- Why it matters: this is a split-brain routing definition for one of the 9
  hardened internal briefs. At minimum it silently 404s the subdomain
  regardless of which rewrite layer Vercel resolves first (both destinations
  are now dead: the static file is gone, and vercel.json's own rewrite never
  reaches the working `/warroom/kelly-interview` route). At worst, if
  `vercel.json` rewrites are evaluated ahead of `next.config.ts` rewrites at
  Vercel's platform/edge layer (plausible — the two systems overlap and
  mixing them for a Next.js app on Vercel is not standard practice), it
  could permanently shadow the correct admin-gated rule for this host,
  independent of whatever `next.config.ts` says. No live evidence either way
  from this environment (network egress blocked) — flagging on repo
  evidence alone: a stale rewrite to a file removed for a security reason,
  never cleaned up.
  - The other four `vercel.json` rewrite entries (`/resume`, `todd-call.arcs.care`
    `/teardown` + `/logictree`, `julia.arcs.care` `/runtime`) are **not**
    drift — none of those hosts are in the 9-brief hardening set, and all
    four destination files (`resume.html`, `todd-teardown.html`,
    `todd-logictree.html`, `julia-runtime.html`) still exist in `public/`
    exactly as intended.
- One-line fix: delete the `kelly-interview.arcs.care` entry from
  `vercel.json`'s `rewrites` array (next.config.ts already owns this host
  correctly) — or repoint its destination to `/warroom/kelly-interview` if
  the two rewrite layers must stay in sync for some platform reason.
