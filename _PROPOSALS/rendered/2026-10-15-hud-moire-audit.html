HUD moire audit

The HUD already draws a moire, but it is made from product roadmap dots, not from echo data. This page says what runs, what is only a picture, and the smallest honest visual that would show real overlap.

§ The short version
What is on screenarcs.care/hud (checked live: arcs.care redirects to www.arcs.care/hud, which serves 'ARCS · Field HUD') is src/organisms/Scope.tsx pinned full screen. Its interference rings are real drawing code, but the ring sources are 11 hard-coded product waypoints plus the navigator. No echo, receipt or Y-gate value feeds them.
What runs underneathThe orthogonal echo detector, the embedding signature and the MOIRE render state all exist. The embedding module has a --self-test that I could not run here (no operators/.venv in this worktree), so 'runs' rests on the 2026-09-27 run record. The 2026-09-27 run found 0 real echoes once the shared-template control removed boilerplate. Cascade as an event, phase-shift events and vector collision have no running code (vector collision is listed as not built in CLAUDE.md).
Smallest honest stepOne echo overlap strip: two stripe families whose spacing comes from each domain's concept strengths. It shows a beat only where a match survives the template control, and shows flat lines with the words '0 real echoes' otherwise. Today that means flat.
§ Decisions waiting on you

D1Build the echo overlap strip, admin-only first?

Recommended: Yes. Build-time JSON from the existing detector, drawn in the HUD side panel behind the same admin check the ziggurat loader uses. Public only after one real echo survives the template control.

A moire drawn from nothing is what the brand promise refuses. Showing flat lines honestly is the feature.

D2Label the current waypoint ripples as illustrative?

Recommended: Yes. One line in the HUD panel: 'Ripples mark roadmap waypoints, not data.' Costs nothing and stops the existing moire being read as evidence.

The ripples are the HUD's only texture and they look like measurement.

D3Merge the clarity and coherence gauges at the question level?

Recommended: Yes. Keep the clarity lens (nci_by_lens.clarity) and retire coherence_pct as a separate gauge; keep HUD coherence as a lattice property under its own name. Define consonance as the gap between stated confidence and closed outcomes (the Accountant already computes calibration at n of 30 or more per cohort).

The compass prompt describes both as 'well-formed' and 'answerable'. The HUD uses the same words for different repo-level counts.

D4Drive per-node grain from evidence counts?

Recommended: Yes, as a second step. Node uncertainty = 1 minus min(1, evidence / 10), evidence = mapped files + commits in the last 28 days, both already in universe-field.json.

This is how zoom shows less certainty where little is known, using data that exists, instead of a fog slider.

D5Fix the L3 label drift?

Recommended: Yes. CLAUDE.md says L3 is cascade. The compass prompt (route.ts) runs L3 as the Kintsugi immune check. Pick one and make the other match.

Anyone building a cascade visual from the L3 label would draw something the pipeline does not compute.

§ Heuristics: for you, and for me
For you (human)
  • Read the short version, then the mechanism map. A green MECHANISM pill has code behind it; a gold METAPHOR pill is a picture only.
  • If a visual cannot go flat when the data is empty, it is decoration. Ask what the HUD shows on 0 echoes.
  • The Lima review is a simulated lens built from general network and hierarchy design practice. It is not his view and nothing was sent to him.
  • Approve D2 and D5 even if you hold the rest. They cost nothing and remove two misreadings.
For the agent (machine)
  • No production change from this proposal. Any build needs an approval recorded against its decision id.
  • Claim only what runs: grep for the symbol before labelling it MECHANISM. 'phase shift' returned zero code hits on 2026-10-15.
  • Fixtures are pre-registered here before any build. Do not tune a threshold after seeing a run.
  • Do not touch _STATE/job-search/ or any VICO file. Run scripts/page_gate.py on any rendered page; em-dashes stay at 0.
  • scripts/proposal_render.py in this worktree is a copy of the relaxed-merkle-130db6 renderer plus one generic 'tables' section; drop the copy when that one merges.

§ Proposed controls and how we will know each works

Each control is a guess until its test runs. A test has a known-bad case that must fail and a known-good case that must pass.

C1Echo overlap strip proposed

Two stripe families, one per domain. Stripe spacing comes from that domain's concept strength for the matched pattern. The strip shows a beat (the moire) with amplitude equal to the match similarity, only for matches that survive the template control. With none, it draws flat lines and the words '0 real echoes'.

Must fail
Pre-registered known-bad, two fixtures: (a) the word-scrambled controls from echo_ridgeline_feed.py (seed 27, 5 runs) and (b) the shared-template fixture (13 verbatim lines in 2 or more domains). Both must render beat amplitude exactly 0.
Must pass
Pre-registered known-good, SYNTHETIC and labelled so: two short domain texts that state the ratchet_irreversibility structure with disjoint vocabulary and no shared lines, same seed. Must render amplitude equal to the detector's similarity within 0.000001 and beat spacing equal to the absolute difference of the two stripe spacings. No real known-good exists yet, because real_echoes_after_template_control is 0.

Test status: specified; fixtures named, thresholds fixed here before any build · line: amplitude 0 on bad, match similarity on good (tolerance 1e-6)

C2Per-node grain from evidence proposed

Each lattice node is drawn with grain 1 minus min(1, evidence / 10), evidence = files plus commits in the last 28 days. Zoomed in on a thin node, you see less certainty, not invented detail.

Must fail
A node with 0 files and 0 recent commits drawn at full sharpness fails.
Must pass
Grain is monotone non-increasing in evidence across all 81 nodes; node zp (0 files) is at maximum grain.

Test status: specified · line: 0 monotonicity violations across 81 nodes

C3Colour channel check proposed

A test asserts that tier colours and gate colours in Scope.tsx share no value.

Must fail
Today's constants (TIER_COLOR.now and GATE_COLOR.pass are both signal.green) must fail.
Must pass
After the change, disjoint colour sets pass.

Test status: specified; fails today · line: 0 shared colours

C4Gauge rows carry n proposed

Every gauge row in ScopeHud prints its sample size and shows a grain marker below the threshold.

Must fail
A render of today's Clarity row without n fails.
Must pass
A row with n and marker passes; consonance with 2 closed receipts shows GRAIN.

Test status: specified · line: n shown on 5 of 5 rows

C5Canvas label floor proposed

Grep fails the build if any canvas font in Scope.tsx is smaller than 11px.

Must fail
The five sub-11px sites fail today (lines 763, 823, 831, 947, 950).
Must pass
11px or larger passes.

Test status: specified; fails today · line: minimum 11px

§ Glossary
Moire
The pattern that appears where two regular patterns overlap at slightly different spacing. It belongs to neither layer alone.
Orthogonal echo
The same shape of behaviour showing up in two unrelated domains, found by comparing structure, not shared words.
Template control
A check that drops lines repeated word for word in two or more domains, so boilerplate cannot pass as a real echo. On 2026-09-27 both detectors found 0 real echoes after it.
Fathom
One of seven depth steps in the HUD, from orbit (F1) down to grain (F7).
Earned fidelity
Showing detail only as sharp as the evidence deserves.
Y-gate
The step that grades how sure an answer is from the answer itself.
MOIRE render state
The Y-gate's rendering for the PARADOX state: reduced weight and an interference overlay.
