Token Tuner

Add ?tune to the address of any page that carries the tuner. Each slider moves one :root token, so every block that reads it moves with it.

What it changes

Only CSS custom properties on the html element: the reading measure, the five spacing steps, the step and body font sizes, and line-height. It never writes a style on a single element, so the one-measure rule holds while you tune.

Paste back

Copy CSS gives one line such as :root{--measure:720px;}. Paste it after the page's last :root block, or fold the values into that block.

Where it may live

Inline it with python3 scripts/token_tuner_inline.py page.html and remove it with --strip. A counterpart send copy must not carry it: page_gate.py --counterpart fails the page if it does.
