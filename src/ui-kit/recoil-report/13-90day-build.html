§ 90-Day Build Arc
1
Day 1–30
Terrain Read
Audit every live Instant Rips growth motion
What's running, what's worked, what's been tried twice
Map the 5 teams' signal flows
Where does learning die? Where does it compound?
Identify the bottleneck in the funnel
CAC, conversion, or retention — pick the highest leverage layer
Output: Terrain brief — first decision receipt the org has ever had on its own growth motion
2
Day 31–60
First Loop
Run one full campaign cycle with the memory layer live
Pre-campaign receipt → post-campaign validation
Wire the signal taxonomy
Categorize what types of drops generate what types of learning
First variance measurement
What did we predict vs. what happened — and why was the gap there?
Output: First compounding receipt — proof the system generates better predictions than gut feel
3
Day 61–90
Propagate
Surface learnings to adjacent BUs
Trading Cards, Live Commerce, Authenticated Merch — what transfers?
Build the CoE case from evidence
If the receipts prove value, the argument for a cross-BU function writes itself
Scope Phase 2 with Chris
What does "force multiplier on the growth org" look like at scale?
Output: Cross-BU brief + Phase 2 proposal — the function that started at Rips now has a case for the whole org
