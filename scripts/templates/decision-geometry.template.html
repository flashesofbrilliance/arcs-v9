Decision Geometry Explorer text-scored

Each decision is scored on 25 cells: five aspects (Decision, Risk, Window, Clarity, Altitude) by five cells, each from L0 (unknown) to L5 (confirmed by an outcome). Every level quotes the text behind it; a cell with no matching text stays L0. This dataset is text-scored: levels come from what each record says about itself, not from a measured receipt, so nothing here reaches L4 or L5. The five aspects collapse to a five-digit shape code, one point among 3,125.

The rung strip shows the altitudes this decision occupies, Executive to Surgical (inferred from wording, so L1 at most). Below it are the selected aspect's five cells. Cells are not paired with rungs: the spec defines no such pairing.

3. Where the shape sits in the 3,125 space

Rows are D then R (25 rows), columns are W then C then H (125 columns); each square is one shape code. Every decision in the dataset is marked; the selected one is ringed.
