# Munger → ARCS Design Doctrine

> Extracted from the full Munger/Buffett corpus through the ARCS lens. Session origin: May 11 2026.

## Five Design Primitives

### 1. Boundary First
The perimeter matters more than the size of the circle. Identify "yes / no / too tough" before forcing a conclusion.
**ARCS**: Tólma Audit + Hubris Gate run before any recommendation.

### 2. Inversion Before Action
Ask how to fail before asking how to succeed.
**ARCS**: BAR / Loki / failure receipt as default first step, not optional add-on.

### 3. Latticework Over Single-Model Answers
Multiple models must converge before elevating confidence.
**ARCS**: ≥2–3 orthogonal lenses required for high-conviction output. Single-lens outputs are flagged.

### 4. Misjudgment Defense
Incentives, social proof, authority bias, commitment bias are the default operating mode of human judgment.
**ARCS**: Kintsugi Immune System as first-class layer, not afterthought.

### 5. Compounding Via Patience
Reward non-action when context is “too tough.” Do not manufacture cosmetic momentum.
**ARCS**: NULL / OM / UNDEFINED states are valid and high-status outputs. “Not yet legible” = success.

## Primitive → Feature Map

| Munger Principle | ARCS Feature | Product Implication |
|---|---|---|
| Circle of Competence | Illumination Radius + Tólma Audit | Show known, unknown, unclaimable before next step |
| Inversion | BAR / Loki / Failure Receipt | Ask “how does this go wrong?” first |
| Latticework | Multi-lens orchestration | ≥2–3 lenses for high-conviction output |
| Human Misjudgment | Kintsugi Immune System | Detect ego, social proof, incentive distortion |
| Patience / Too Tough | NULL / OM states | Normalize “wait,” “not yet,” “insufficient edge” as wins |

## Product Doctrine

ARCS should be **calm, anti-theatrical, and resistant to cleverness-for-its-own-sake**.

> *Build a system that helps users earn the right to claim more — not by hyping potential, but by compounding receipted judgment, expanding the circle deliberately, and making “I don’t know yet” one of the highest-status outputs in the system.*

## The Emotional Dimension Munger Left Out

Munger’s circle protected outward (from incompetence) but not inward — from the weight of genuine mastery, the isolation of depth, the Prosōpon gap.

ARCS adds the inward guard. **The circle is bidirectional.**
This is the contribution of the May 11 2026 session.
