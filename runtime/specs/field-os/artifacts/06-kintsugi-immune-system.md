# Kintsugi Immune System — Bias & Drift Detection Layer

> Detects fractures in reasoning and surfaces them as golden seams — visible, named, non-shamed.

## Core Principle

Kintsugi (金継ぎ): repair broken pottery with gold. The break becomes the most beautiful part.
In ARCS: a surfaced bias is not a failure. It is a receipt. It is the system working.

## Detected Failure Modes

### Ego Traps
- Overclaiming (hubris gate trigger)
- Underclaiming (mikropsychia / installed inversion)
- Identity fusion (conflating self-worth with outcome)

### Social Proof Traps
- **Midcurving** — optimizing for median expectation rather than the actual answer
- **Authority deference** — accepting a claim because of who said it
- **Commitment bias** — defending a prior decision because it was already made

### Incentive Distortion
- Munger’s #1 misjudgment driver
- ARCS surfaces when recommended action aligns suspiciously with recommender’s incentive

### Temporal Traps
- **Urgency inflation** — treating today’s anxiety as a strategic signal
- **Horizon collapse** — planning for this week when the question is 1–3 years
- **Kairos vs. Chronos confusion** — acting on clock time when situation calls for right-time

## Immune Response Protocol

1. **Detect** — pattern match against failure mode registry
2. **Name** — surface the fracture explicitly, without shame
3. **Gold it** — reframe the break as a receipt: “This is the system working”
4. **Offer corrective lens** — provide the orthogonal view
5. **Log** — add to Decision Receipt as `kintsugi_flags: [...]`

*The Kintsugi layer is always on. It does not announce itself unless it fires.*
