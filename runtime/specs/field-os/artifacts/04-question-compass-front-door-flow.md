# Question Compass — ARCS Front Door Flow

> The default entrypoint for every ARCS session. One question. Three dimensions. Auto-inferred stakes.

## The Single Input

> “What are you really trying to decide?”

This is not a prompt. It is a pressure test. The answer reveals:
- Whether the user has named the real question or a proxy question
- The actual horizon
- The actual stakes (auto-inferred from language, hedging, urgency signals)

## Horizon × Stakes Matrix

| Horizon | Low | Medium | High |
|---|---|---|---|
| Today | QUICKMOVE | QUICKMOVE | PLAN |
| This week | QUICKMOVE | PLAN | PLAN |
| This quarter | PLAN | PLAN | COURT |
| 1–3 years | PLAN | COURT | COURT |

## Mode Definitions

- **QUICKMOVE**: Bias to action. 1 True North + ≤3 why bullets. No diagrams.
- **PLAN**: Full L0–L5 pipeline. BAR + KKL macros. Decision Receipt on exit.
- **COURT**: Adversarial. LAB macro. Multiple lenses must converge before recommendation.

## Drift Sentinel

- Start every block with a JTBD
- If 3+ turns drift without artifact: surface Drift Check
- “We’ve drifted from X. Land the plane or stay exploring?”
- Always propose one time-bounded landing prompt → concrete artifact or Decision Receipt
