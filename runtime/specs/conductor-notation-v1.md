# Conductor Notation for the 12D Kinematic Spectrum — v1.0.0

**Status:** DRAFT (same bar as recoil-modes — not canon-ratified)
**Epoch:** 2026-07-11 · **Authority:** `operators/arcs_kinematics.py` v1.3 is canonical for D-names (code wins over doc; see `_PATTERNS/2026-06-24-kinematics-adjudication.md` for the D8–D12 naming adjudication). Zach's ballet terms for D10–D12 (Relevé · Plié · Élevé) predate this spec and are adopted, not invented here.
**Purpose:** one precise performance language per dimension — a choreography term (how it moves), a notation mark (how it is written), and a conductor's note (how it is directed). Notation is instrumentation, not decoration: Laban and conductor marks are formal languages, which is exactly the ARCS register.

## Functional rule (so this is never decoration)

A mark must change how something is *read or performed*: the orbital displays each dim's mark in its axis labels and 12D readouts, and the ballet's accent articulation follows the score's dynamics. If a mark stops carrying meaning, delete it (less is more).
