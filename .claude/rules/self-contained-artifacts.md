13. **Self-contained artifacts/pages (single-file HTML) — measure + run the target repo's OWN gates before shipping.** The intermediate-width wrap-regression keeps recurring. Rules, most enforced by `scripts/artifact_wrap_lint.py`: (a) BODY / card reading text uses ONE shared px `--measure` — NEVER a per-element `max-width:NNch` (`ch` gives every text role a different right edge; the misaligned rag reads as broken wrapping); (b) a bordered/filled callout is the card that carries the measure — never separately cap the text inside a card, **but a card must still end where its siblings end: shrinking a card to the measure only moves the dead right gutter up one level (2026-10-15, `_PATTERNS/2026-10-15-sibling-edge-root-cause.md`). Fill the card to the lane, or pair a narrow measure with a second grid column. `scripts/card_gutter_check.mjs` now fails a card or text block that ends short of its widest sibling; opt out only with `data-lane="narrow"`.** **(c) LEDES ARE THE EXCEPTION — never cap them at the narrow body measure.** A hero/section lede (and any full-lane intro paragraph) spans the SAME width as its heading / lane (`max-width:none`, inheriting the container). A lede capped narrower than its heading reads as a broken/abridged block with a dead right gutter — Zach flags this every time (EXCEPTION, 2026-09-29: text INDEX pages such as good.arcs.care/series/* put lede, rows and footer rule on the 680px measure) (memory `design-full-width-lede-matches-heading`; this is a standing preference that OVERRIDES the generic narrow-measure default, NOT a bug to "fix" back to `--measure`). Note the failure symptom "wraps too narrow / early" is invisible to overflow/clip gates (narrow never overflows) — so ALSO eyeball the lede-vs-heading right edges, don't just trust the sweep. Then VERIFY with the target repo's own gate, not an ad-hoc sweep: full band 360–1440 incl. the 700–1000 zone. `zachharris-xyz` has `npm test` / `test:scan` (Playwright regression + axe); ARCS artifacts run `artifact_wrap_lint.py` + a screenshot sweep at ~790px AND a lede-width eyeball at ~1280px. Em-dashes stay at 0.
