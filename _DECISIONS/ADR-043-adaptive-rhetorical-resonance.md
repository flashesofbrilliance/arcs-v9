# ADR-043 — Adaptive Rhetorical Resonance as a first-class artifact design axis

**Status:** Accepted · 2026-08-10
**Relates to:** ADR-039 (refusal to overclaim), ADR-042 (coaching exoskeleton wedge); memory
[[adaptive-rhetorical-resonance]]; DEWY receipt `runtime/recoil/generated/2026-08-10-adaptive-rhetorical-resonance-receipt.json`.

## Context

We already derive a counterpart's register from the recoil / ambition read (how they think, what they value).
Observed by Zach (2026-08-10): across the entire Todd/PRL artifact family we have been consistently tuning the
*rhetoric* — word choice, framing, cadence, what is foregrounded — to Todd's register (calm, "boring and
predictable," capital-steward justifiability, low-drama), while the underlying facts stayed invariant. This was
implicit craft. It should be named and governed so it is reproducible and does not drift into flattery.

## Decision

**Adaptive rhetorical resonance is a first-class design axis for counterpart-facing artifacts.** The FACTS are
invariant; only the DELIVERY (frame, word, cadence, emphasis, emotional key) is tuned to resonate with the
counterpart's register as read from the recoil. The method crosses; the subject does not.

Distinct from its neighbors: [[met-at-your-level-onramp]] governs entry *altitude*;
[[audience-model-derivation-rule]] governs *modeling* them pre-contact; this governs the rhetorical *delivery*.
It operationalizes [[zach-north-star-resonance-gradient-field]] at the artifact layer.

## Guardrails (non-negotiable)

- **Facts invariant.** Resonance never bends a claim; it only re-voices it. If tuning changes what is true,
  it is fabrication, not resonance — stop.
- **The register gauntlet + honesty gate still run** ([[gauntlet-tuned-to-register-catches-what-detector-cannot]]).
- **Verify against their own words** — echo what THEY said, not what we would say ([[counterpart-vantage-premortem]]).
- **Never flattery.** Resonance lowers resistance to a true claim; it does not manufacture agreement.

## Consequences

- Add resonance as a checked axis in the forge / recoil-ship pipeline (alongside verify/honesty/craft-floor).
- Durable capture in machine memory (auto-loaded) + this ADR + a DEWY receipt.
- Evidence base: the Todd/PRL family (this session) — the go-live evidence, kickoff, UAT, and deck all speak
  his register; the spec-answering copy uses the exact "Option B" language he was already given.
