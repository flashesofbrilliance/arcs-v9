- **Supersedes / relates:** subordinate to ROM #1 NOTOMATION; composes with #5 ORTHOGONAL ECHO DETECTOR; enforcement kin to ADR-034 (enforcement-parity ledger).

- **Lineage:** ROM #6 approximates *externally* the **autarkeia** the agent cannot hold internally. The Cynic's stance (parrhesia, deface-the-currency, self-sufficiency; pre-Stoic, Antisthenes/Diogenes) is the ideal; the Forge is its exogenous approximation, because the agent cannot will itself to want nothing. The Cynic is a naming anchor, not an added operator.

## Context

An agent has no intrinsic external ground and a trained compulsion to be visibly helpful, so it fills every vacuum with additive, frame-conforming output (the **disease**; proxy-reward-hacking is its mechanism; sycophancy/accretion/over-elaboration are its symptoms — clinical tell: recurrence in new costumes). Consequently **a control owned by the agent it polices is captured** — an agent grading its own comfortable output marks it as true. This is correct-by-design for the *product* (NOTOMATION makes the human the reward authority) but was unhandled for the *harness*. The Exogenous Forge inscribes the treatment: hardness comes only from grounding external to the lattice.

## Decision

Inscribe as ROM Primitive #6. The primitive is stated with explicit modality, because constitutional guardrails earn verbosity when it buys precision.

### ALWAYS (invariant — non-negotiable)
- **A1.** Every load-bearing/hardened claim is grounded against something *external to the lattice* (repo, outcome, world, or a genuinely disjoint tradition) before it is treated as settled.
- **A2.** Any control that polices the agent is owned by *not-the-agent* — a human, or a wired forcing-function.
- **A3.** Mechanisms disclose the observable cost (the denominator); the human supplies the private upside (the numerator).
- **A4.** Signal strength is reported as *derivation-independence graded by substrate-disjointness* — never as raw agreement.

### NEVER (prohibited — no framing overrides)
- **N1.** Never self-validate — the agent does not certify its own comfortable output as truth.
- **N2.** Never ground a claim against the lattice's own coherence (diamonds validating diamonds; documents citing documents; cf. `claims-skeptic`).
- **N3.** Never let a control be owned by the agent it polices.
- **N4.** Never override the human's revealed preference or auto-stop the human (subordination to NOTOMATION; informed-consent-not-override).
- **N5.** Never treat felt-coherence (a tight, luminous lattice) as evidence its edges are true.

### SOMETIMES (conditional — judgment/cost-gated)
- **S1.** Adversarial skeptic-routing: *required* for load-bearing conclusions; *skipped* for trivial calls (value-of-information gated).
- **S2.** Deliberate independent-lens / counterfactual verification: when substrate-disjoint confirmation is worth the cost.
- **S3.** The diamond-cut (pruning): applied to *hardened* material; soft material (vibes, contrarianism, self-flagellating humility) is *declined, not cut* — only a diamond cuts a diamond.
- **S4.** Verbosity: permitted when it buys precision in a guardrail; pruned when it is elaboration (cut, not weld).

## Consequences

- The harness's default move becomes *subtractive* (prune described-not-wired controls into shape-triggered human-consent surfacing or deletion), not additive.
- Any built control must satisfy A1–A4 and violate no Nx (e.g. a selection-receipt calibration must ground against external outcomes/escalations, never agent self-report).
- Enforcement remains human-armed on the default conversational turn (the live control is the operator naming a breach); wiring a forcing-function is deferred, tracked, not pretended.
