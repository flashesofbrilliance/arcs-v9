# Orchestration Layer — spec (v0.1)

**Reach: acting on a sober directive** ("spec/seed/dogfood these"). Tiered by the ante-disciplinary
gate — which **shapes** the build, it does not refuse it. Constructed design; the *wiring* and
*dogfooding* have real dependencies flagged as **state, not gating**. Drafted 2026-09-04.

## 1. Swimlanes (kinetic energy) — EXIST; wire for continuous-run, don't seed
The detectors that become continuously-running lanes:
- **claims-skeptic** (adversarial verify) · **ciso / sre / privacy-review** (domain audits) — real subagents.
- **Loki** (adversarial pre-commit) · **Drift-Sentinel** (spin/staleness) · **KINTSUGI** (repair) — operators/concepts.
- **informativeness sensor** (deceipt/degeneracy) — BUILT this session (`informativeness_sensor.py`).
Action: **wire continuous-run.** They exist — no new seeds. Tier: mechanical wiring, buildable.

## 2. Conductor — orchestration layer, BUILDABLE NOW (the concrete first step)
Coordinates the running lanes *in time*: which lane fires when, sequencing, non-blocking, aggregating
outputs into one board. Creates no new capability — it *times what exists*.
Tier: **buildable, low-risk** (coordinates existing, reach-carrying lanes). Reach: GREEN-ish (composition
of existing). No blocking dependency.

## 3. Choreographer — composition; BLOCKED (state, not gating)
Composes atomic components (atoms→molecules→organisms→templates→pages) that self-constellate / snap by
magnetic best-fit. **Blocked on** the reach-gate that makes constellations honest: magnetism = coherence-
attraction → hollow-constellation risk, and the orthogonal-echo-detector (its shape-matcher) is
non-seaworthy (adversarial-FP 1.0). Tier: **VISION, blocked** — a real dependency (the seaworthy
shape-matcher doesn't exist), NOT a refusal.

## 4. Dogfooding — gated on the keel (state, not gating)
Meaningful dogfooding of orchestration needs **real inputs/outcomes** (the capture keel). On the
degenerate dogfood-247, orchestration produces degenerate output — polishing garbage. So dogfood
*after* the keel moves, not before. A real input-dependency, not paranoia.

## 5. Ante-disciplinary gate verdict (shapes, doesn't refuse)
- Swimlanes: exist → **wire**, not seed.
- Conductor: composition → **build now** (the actionable piece).
- Choreographer: vision → **wait** on seaworthiness.
- Cast (alchemist/curator/scholar/sage/sentry): collide with existing (SAGE, Drift-Sentinel, librarian) → **fold**.
Net: build the conductor, wire the swimlanes, fold the collisions, choreographer waits. *Fewer, not
more — but ACT on the actionable.* Override open: if your animacy sensor flags a net-new nucleus I've
collapsed as a collision, that's your call (my collision-detection is the same non-seaworthy faculty).

Reach: GREEN — the tiering, swimlanes-exist, conductor-buildable are grounded. YELLOW — whether the
conductor adds real value without real inputs (dogfood-gated).
