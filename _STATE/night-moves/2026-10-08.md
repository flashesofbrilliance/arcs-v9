## 🧠 What we learned
- Look out before you look in: I started a cross-cutting a11y sweep and fix batch without first scanning concurrent sessions; five open PRs overlapped, and a redirect caught it before any commit landed. The gather's `--all` branch sweep (or the neighbor scan (PR #1099)) is the cheap check: `[[look-out-before-look-in-scan-concurrent-sessions-first]]`.
- A gate is only trusted once it fails the bad build and passes the good one: the anchor-snap check failed the broken page first (every phone jump landed under 218px of chrome). `[[run-the-repos-own-gates-before-shipping]]`, `[[mechanized-frontend-gate-is-tripwire-not-verdict]]`
- A second engine exposes hidden assumptions: Comet failed a fixed 150ms scroll wait that Chrome tolerated. A direct probe separated "gate wrong" from "page wrong". `[[page-gate-strict-matrix-cross-browser-comet-axe]]`
- Automated accessibility passes are a floor: axe reported zero on my page and the smoke file still found two real interaction bugs (Close reopened the chip; a chip ran off a 320px screen).
- A tool can rewrite far more than you asked: the impeccable CLI changed 1,421 lines of config for a 9-line exemption. `[[impeccable-ignores-cli-rewrites-whole-config-hand-add-one-entry]]`
- Reading accommodations: spacing and size beat special "dyslexia fonts", and a named person's condition does not go on a counterpart-facing page. `[[feedback-non-technical-pages-slider-chips-reading-options]]`
- Voice and honesty: first person singular for a solo practice; claim "powered by ARCS" only where a tool runs. `[[feedback-counterpart-text-first-person-singular-no-royal-we]]`, `[[manana-solo-practice-arcs-engine-claim-only-what-runs]]`
