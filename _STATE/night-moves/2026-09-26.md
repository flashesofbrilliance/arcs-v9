## 🧠 What we learned
- **A per-file gate that only fires on touch lets whole corpora drift silently; the fix is a batch `--all` gate on the always-run path.** Fire it on round 2, not round 15. [[run-the-repos-own-gates-before-shipping]]
- **Classify detector contrast findings against the ACTUAL rendered surface read from the CSS, never the detector's `#ffffff`/`#000000` fallback**: artifact-vs-real falls out of the real ratio. [[verify-recalled-defect-with-dom-measurement-not-eyeball]]
- **A robots gate that checks presence-not-value lets a conformance sweep add the tag to noindex fragments without ever exposing them**: the int/ext air-gap survives the sweep.
- **Atomic design SSOT + a component-source gate** makes "build a new surface" reuse-by-construction. `ADR-083`
- **Write-lock the OSS publish decision before shipping** (npm name, license, distribution). `ADR-82`
- **A generator can clobber a post-publish hand-fix**: diff the fresh render against live before republishing, and back-port to the template. [[regen-from-generator-can-clobber-postpublish-handfix]]

## 🔧 The new shape of tools for JTBD
- **"Ship a public artifact" is now honesty-gated by a wall, not a single check**: slop (mechanical + metrics + provenance + judgment), contrast (per-file + batch ratchet), head-meta conformance, evidence ledgers, and receipt-timing all fail the build on their own axis. The job changed from "lint before ship" to "the ship-gate is a standing immune system the artifact must pass through."
- **"Stand up a new surface" is now reuse-by-construction**: the ui-kit atomic SSOT + component-source + token-source gates mean a net-new page assembles from blessed primitives and a fresh palette re-declaration is blocked, so drift can't be born.
- **"Publish internal state as a public good" is now a factory, not a bespoke build**: the belief-log mirror generalized into `projection_factory.py`, so any internal ledger (beliefs, signals, gauntlet log) projects to a gated public view through one path.
- **"Prove work happened" is now deterministic from git**: `signal_receipt.py` derives shipped-vs-reworked from the commit graph, so the record is computed, not narrated.
