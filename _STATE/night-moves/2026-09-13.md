## 🧠 What we learned
- **A mechanical drift-checker is only as good as its field's format.** `seedbank_drift_check.py`
  does a literal `os.path.exists(local)`; 4 seeds authored `local` as prose-with-citations, so a
  correct checker flagged 4 false positives. Lesson: countable fields need a bare-value contract,
  or the check needs to parse structure, not just exist-check a blob.
- **Shared anchors collide on ids, not bytes** — two sessions minted the same class of fix
  (seedbank local-paths) within ~70 minutes of each other, on different worktrees, neither aware
  of the other. Re-fetch and check for existing work before minting, especially on shared/global
  state files (`_SEEDS/index.jsonl`, ADR counters). See [[shared-anchor-append-refetch-before-write]].
- **The naive `ahead` count is not an audit** — patch-id-based worktree comparison (this session's
  `cruft_sweep.py` and the parallel Triune Stream A sweep) found real content that a raw commit-count
  diff would have both over- and under-stated.
- A static front-end gate is a tripwire, not a verdict — scope/cascade/intent/staleness are the
  recurring traps. [[mechanized-frontend-gate-is-tripwire-not-verdict]]
- Ship behind the target repo's *own* gates; when a fix doesn't take, suspect the gate itself before
  the code. [[run-the-repos-own-gates-before-shipping]]
- The recurring "text wrapping bug" is one class with five failure modes and one wired gate — diagnose
  the mode before reaching for a fix, and never trust a green overflow test for a visual complaint.
  [[text-wrapping-defect-class-and-gate]]
- For startup/founding-team roles, lead founder-first, not operator/PM — a warm, strong-materials
  pass still fails on company-shape if the pitch doesn't lead with the right frame.
  [[blacksmith-reject-lead-founder-first-for-startup-roles]]
