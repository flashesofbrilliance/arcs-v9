## 3. What we learned
- Fix a flagged defect at its source with a gate, so the fix compounds across every surface ([[rca-first-fix-compounds-into-the-kit]]).
- For visual work, render about three options per block and let Zach pick in place ([[visual-work-three-rendered-options-per-block]]); the option board (2227) and ranker (2257) make that a tool.
- When an axe upgrade flags an old defect, fix it on main and rebase, rather than raising the baseline ([[axe-upgrade-flags-old-defect-fix-on-main-then-rebase]]).
- Counterpart copy is first person singular; grep for we, our and us before every send ([[feedback-counterpart-text-first-person-singular-no-royal-we]]).
- "Ripe" is not "done": read each loop's note before closing it ([[ripe-is-not-done-read-each-loop-tag]]).
- Long or nested-quote shell goes in a script file; bash 3.2 refuses it otherwise ([[long-inline-shell-goes-in-a-script-file]], [[git-rev-parse-short-takes-one-rev]]).
- A dry run that never commits cannot see a failure the commit hook would catch: the stale-refresh order bug surfaced only on the first real run (2316), so every run now ends with the hook's own check.
