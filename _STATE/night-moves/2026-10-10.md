## 🧠 What we learned
- "Merge when CI is green" means every check has a conclusion, not that the finished ones passed: #1231 merged with fe-smoke still running on the merged head. It passed afterwards; the receipt was corrected with a new row (`2026-10-10--louisville-nav-receipt-correction-pr1231--ZH`) because updating a logged receipt was declined. Check for zero pending before merging.
- A relay that forwards every idea becomes a scope pump; check each ask against the brief before sending it. [[relay-scope-check-against-brief-before-forwarding]]
- Usage spikes come from context size, not work: 95% of the last 24 h ran above 150k context. Fold at 80k; molt at 100k or 4 h. [[session-budget-discipline-cap-parallel-molt-long]]
- Proving CI goes red must not need a hook bypass; plant the failure inside CI. [[feedback-prove-ci-red-without-hook-bypass]]
- Bank harness lessons in arcs-v9, never on the customer surface. [[feedback-always-bank-harness-lessons-detached-from-customer-surface]]
- A number shown by hand drifts; render every shown figure from one source and fail the build on staleness (take-home K35). [[provenance-gate-every-metric-cites-evidence]]
- Gates must scan everything that ships, including the history bundle (take-home K34).
- A worktree session still loads skills, commands, agents and settings hooks from the main checkout; where that checkout is parked decides which tools every session runs. [[claude-config-resolves-from-main-checkout]]
- When our own test, premise or tool was wrong, log the seam and the repair as it happens, not later. [[kintsugi-seam-when-the-test-was-wrong]]
- Work that exists only in one checkout is invisible to every other session; two tools sat unmerged for two weeks while the digest reported them missing. Salvage to a new remote branch name, never a force push.
- Run rendered contrast checks with reduced motion and a settle wait, or fade-ins read as fake 1.1:1 failures. [[a11y-measure-settled-page-not-animation-frame]]
- A lint rule caught what the build and the browser did not: resetting state from an effect worked on screen but is a render loop risk; derive it instead. #1174 smoke run, fixed on the branch.

- **"Hand a client a build they can run cold"** is now testable: the onboarding docs run from the built ZIP in CI, and the e2e dry run compares answers against outputs pre-registered before the run.
