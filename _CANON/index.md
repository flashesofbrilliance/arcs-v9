## How to use this index

- **Building features?** Start with Book II (Parts I-VI). They define what's allowed and why.
- **Designing the UI/UX?** Read trust-contract.md + Part I (coherence mapping).
- **Explaining ARCS to someone?** Use Litepaper or Manifesto, not the canonical parts (too dense).
- **Settling an architectural debate?** Grep the ADRs (_DECISIONS/) first, then Book II Parts II-III.
- **Need to know what to gate on?** Search Book II Part V (Accumulation Protocol) for drift/gate rules.
