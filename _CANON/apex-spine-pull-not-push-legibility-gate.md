# Apex Spine — Pull, Not Push: the pre-render legibility gate

> An associative index, not a flat record. The understanding lives in the links between dated,
> attestable terminals. This page carries how one rule was named from outside three times, encoded
> once, drifted, and re-encoded as a gate that can stop a page.

**Thesis (ADR-075):** a cold reader arrives in a receptive *state*, not with a trait. Every
counterpart surface opens with the verdict and lets depth be pulled. The author cannot see this
from inside; only an outside vantage reads the author half of a reader-side signal. So the rule is
not a memory. It is a gate, with a calibration set that grows by one page per counterpart verdict.
