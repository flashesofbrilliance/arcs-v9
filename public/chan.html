01
MISSION
Decisions are positions on a manifold under pressure.
Most AI products answer questions. ARCS's governing premise is different: a good decision tool doesn't decide for you — it makes visible where you actually are (what's fog, what's clear, what's contested) and which direction is uphill. Every session produces a DEWY receipt (Decision · Entity · Window · Y-gate) — an ex-ante statement of what's expected, scored against what actually happens. That expected-vs-actual delta is the same evaluation primitive the AI Foundry role is built around: define quality for a probabilistic system, catch drift before a user does, close the loop with real outcomes.

02
ARCHITECTURE & EVALUATION
L0–L5 pipeline, DEWY receipts, Y-gate — evaluation is load-bearing, not bolted on.
L0–L5 pipeline — atomic signal → coherence → path survivability → cascade → cross-domain → global coherence. Every user question runs the full stack before a receipt is written.
Y-gate, 12D manifold — polarity × conviction × stability collapse to a render state (GREEN/YELLOW/RED/FORK/SCRATCH/DELTA/PARADOX/DRIFT). The UI never renders higher-fidelity than the data earns — no confident-sounding hallucination dressed as a clean answer.
DEWY receipt schema — machine-readable JSON Schema (Draft 07) is the source of truth; Prisma models conform to it, not the reverse. Schema-first, not vibes-first.
Anti-hallucination / anti-sycophancy safeguards — source-quality grading, evals gating every receipt write, explicit HOLD states when a window/entity field can't be inferred confidently rather than guessing.
03
GOVERNANCE, SECURITY & TRUST
272 decision receipts on the architecture itself. Nothing ships without a paper trail.
Every material build decision — not just product features — gets its own Architecture Decision Record: what was decided, why, what was rejected, and the consequences if it's wrong. 272 ADRs currently on file, indexed and queryable. Security posture: row-level security (deny-all by default, app-layer user isolation), Auth.js v5 magic-link sessions, a documented reasoning trail for why `auth.uid()` row policies were deliberately rejected in favor of app-layer gating (Prisma connects as a superuser; the naive RLS pattern would have been theater, not real isolation). A public trust contract commits to specific, falsifiable claims about how the system handles data and where a person can catch it at the fork if it drifts.

05
ROADMAP
What's next — named, sequenced, and honestly gated on evidence.
L6–L7 ENGINE
Ecosystem-level and meta-governance layers above the current L0–L5 stack — gated until real-corpus volume justifies the added complexity, not built speculatively.
ATG (TRIBUTARIES)
Every response surfaces 2–4 adjacent threads: the meta-question beneath the stated one, an uncomfortable constraint, a cross-domain reframe — deepening single-turn answers into a navigable space.
KAIROS DETECTION
Timing/window inference at scale — designed, machinery exists in the operators library, gated behind a receipt-volume threshold before going live.
OBSERVABILITY LATTICE
The inferred-goal-DAG model (ADR-023) scales from a static replay demo into a live, self-updating structure once enough receipts exist to measure a real baseline against.
