Recommendation — MVP
Tidio AI on WordPress · SugarCRM via REST API · Zapier upgraded if API access blocked
Why Tidio: WordPress native plugin (5-min install on WP 7.0), visual conversation flow builder that Todd's team can maintain without a developer, built-in AI fallback for unmatched queries, session memory for return visitors (critical for a 6–12 month sales cycle), documented SugarCRM integration via REST API. Starts at $29/mo — lowest friction, lowest cost, and the flow builder makes the branch logic visible and editable by Todd.

SugarCRM bridge: Use SugarCRM REST API v8 directly (no Zapier required). Tidio supports webhook output → Node function → SugarCRM POST /Leads. If direct API is blocked, upgrade Zapier to Starter ($19.99/mo) as backup.

Do not build custom for MVP. The branch logic design is where 80% of the value is, not the chatbot platform. Platform can be swapped in Phase 4 when the AI recommendation layer is ready.
