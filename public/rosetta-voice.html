Say the bashism. Hear the portable line.

Speak a shell construct that breaks when a script moves between bash 3.2, bash 4+, zsh and POSIX sh. Rosetta Voice answers with the fix from rosetta-shell, shows which shells break, and reads it back. What it heard is shown word for word, so you can check every step.

Your voice and privacy

  • This page receives only the words, never the sound.
  • Speech recognition is done by your browser. In Chrome and Edge that sends your audio to the browser maker's speech service (Google or Microsoft); Safari uses Apple's. ARCS stores nothing. If you prefer, type instead: it works the same.
  • Read-aloud uses your device's built-in voices.

Not proven yet

  • It knows the six constructs rosetta lint flags. A clean answer is not proof a script is portable; rosetta crossrun is.
  • Spoken matching uses keywords. When it is unsure it says so and shows what it heard.
  • Voice input needs a browser that offers speech recognition: Safari (on iPhone, with Siri and Dictation on) or Google Chrome. Comet, Firefox and other iPhone browsers get typing only for now.
