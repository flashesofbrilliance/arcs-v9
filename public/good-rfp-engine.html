Answers with receipts,
or a plain “not covered.”

An RFP answering engine. Ask about a solicitation and its amendments; get an answer with the exact clauses it rests on, or a plain “not covered.” Python standard library only. It runs on your machine as an MCP server for Claude Code or Claude Desktop.

↓ Get started llms.txt AGENTS.md
register the server · Claude Code
claude mcp add rfp-intelligence -e MODEL_PROVIDER=mock -- python3 /ABSOLUTE/PATH/mcp/server.py

Use MODEL_PROVIDER=claude with an Anthropic key, or local to keep everything on your machine with Ollama.

What comes back

real output · synthetic RFP

The RFP here is synthetic, based on a real-world example.

status   answered
answer   Section 7.1 (Bid Deposit) is revised: the bid deposit is increased from $20,000 to $35,000.
cites    RFP 7.1 + Amendment No. 1 A1.2
notes    7.1 is superseded in part by A1.2; the amended value governs
gate     fast path: verbatim governing text, no model call

With an injected fault the model claims “$80,000 or 12%”. Neither figure is in the cited clause, so the summary is withheld: verbatim FAILED: ['12%', '$80,000'].

Six rules, enforced in code

not prompts · checks
Shows its source

Every answer points to the clause it came from.

Numbers match

Amounts, dates and percentages match the text exactly.

Latest wins

If an amendment changed it, you get the new value.

“Not covered” counts

If the RFP doesn’t say, it tells you so.

Facts, not decisions

It won’t write your bid or tell you whether to bid.

No guessing

Without a model, you get the clauses, not a summary.

What was measured

2026-10-29 · re-run before quoting
5 of 5 pass

Deterministic checks through the MCP server, identical to calling the engine directly.

8 faults caught

Timeout, garbage, fake clause, invented figures, changed figure, superseded figure, drafting, bid verdict.

3 not yet run

Prompt injection, currency conversion, missing appendix need a real model. Without one they return unavailable, as designed.

Not proven yet: no calibrated confidence score; keyword retrieval, no embeddings; figures are checked, meaning is not; plain text in one numbering style; built for RFPs, not contracts.
