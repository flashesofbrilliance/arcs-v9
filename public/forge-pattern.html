02 m · strata · clearing
the layers of ground

Drill down and the layers sort into two kinds: what varies, what holds.

The counterpart lives in the top layer. Every layer beneath it is shared by every counterpart who has ever passed through the forge, the generator’s global memory. Variation is confined to the surface. The deeper you go, the more invariant it gets.

Args · SSOTper counterpart · varies

The only thing that changes between two runs. --surface picks the form; --data is the one JSON that carries this person’s belief-flip, seam, register, and ask. This is the polyform.

Rendershared machinery

Five surface functions, onedoor · receipt · codex · diamond · profile, and a fixed block grammar. The same code renders Robin Arms, To Sir With ❤, The Data Narrator, McKinsey in a Box. Nobody hand-builds a page.

Gatesthe floor · refuses to write

Three gates run on every render: verify_html for voice and canonical tokens, honesty_and_attribution so every claim is anchored, and temporal_provenance (ADR-044) so no unhedged aspiration ships. ARCS runs on Claude today. Fail one, nothing is written.

Operators · Tokensthe core · global memory

The board that reads the call (Loki · Bayesian · BAR · SAGE · Kairos, conducted by Operator 20), the one canonical token source (_tokens.css, ADR-009/031), the divergence discipline. This is bedrock. It does not know or care which counterpart is above it.
