Five fixes, ranked

Ranked by the auditor from the gaps above. Each names the gap it closes.

  1. Commit the outbound-send deny as config, with a test that 'send the reply' on another channel yields a draft and a question, never a send. config + test · closes: config not committed
  2. Stamp each outbound or irreversible action with its own event time in the record. process · closes: no event time
  3. Log one record per release: what shipped, who approved it, which automation ran it. process · closes: receipt missing
  4. Keep CI output with the merge as a check run, not a line in a commit message. CI · closes: no CI evidence
  5. Record the tool and account that performed each send in the action log. process · closes: provider not confirmed

What this audit cannot see

  • It reads only the committed record. Work that never reached the record is invisible; that is the finding.
  • It is not a compliance certification. It measures reconstructability.
  • It never rates people. It reads the record, not the team.
