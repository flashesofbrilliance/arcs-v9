ARCS Internal: design spec, recommendation and plan

The gate ladder

Every check that can stop a commit or a merge, built from the bottom up and mapped to the ARCS primitives it defends, so the decision structure can be tested instead of trusted.

Why
Two gates were wrong today, and both errors surfaced only because someone looked. A gate system with no way to see its own mistakes keeps them.
What
A ladder that derives each layer from the one below: atoms (single verdicts), molecules (gate scripts), organisms (the commit hook and each CI job), templates (the shape of a check) and pages; then a second ladder of primitives (the seven ROM primitives), operators (the periodic table) and protocols (commit, merge).
Why now
The shadow eval landed today (PR 2350) and found 32 bypasses that a later fix followed, but it cannot say which primitive each one broke. That needs this mapping.

Design spec

Two ladders, one rule: each layer comes from the one below

Nothing is declared from the top. A layer is computed from the layer under it, and a mapping exists only where the repo already holds evidence for it. Counts are generated from runtime/specs/gate-taxonomy.json and _QUEUE/induced-backlog.jsonl.

Invariants the ladder keeps

  • Derived, never declared. Every layer is recomputed from its source; --check fails when the file differs from a rebuild.
  • Evidence or UNRULED. A primitive or operator is attached only where the hook, a ruling file or a real import says so. Absence is shown as a gap, never filled.
  • Label classes never merge. Replay-confirmed, human-labeled and model-labeled stay separate, so judgment is never reported as an outcome.
  • Provenance on every node. Each atom carries the sha that wrote its hook line; each molecule carries the commit that wired it and any ADR the repo already cites for it. An ADR is linked only where one is cited, so the gap is visible.
  • One document shape at every layer. runtime/specs/gate-taxonomy-docs.jsonl holds every node as the same record (id, layer, text, meta, parents, children, content hash). A blob store takes the file as is; a vector store embeds the text and re-embeds only what changed.
  • The tool is tested like a gate. Its own errors were found the same way: a warning regex matched a comment, 30 gates had no atoms, a generator was credited with 12 operators, a prose mention was counted as a page reader, and CI-only gates were missing. Each was fixed at the source.

Finding

Write-lock lives at the protocol layer, not in any atom. No hook check enforces a one-way door; the merge protocol does (safe_merge, the merge-commit setting, receipts). The fractal test in section 4 should expect some primitives to appear only at higher layers.

Finding

No gate uses an operator. The periodic table has an Immune (18), a Loki (23) and a Librarian (21), and none of the 115 gate scripts imports them. Either the gates are the operators in practice, or the operators are not yet load-bearing. That is row gate-operator-binding.

Position

TypeSafe classifies the residue only. Replay settles what history can settle; TypeSafe labels what is left and is graded against replay. It stays held: no key on this machine, and your egress rule allows only already-public text.

Experiment

Does the classification hold its shape?

If the decision structure is built on self-similar invariants, a case should get the same label whichever order you measure in, and the same primitive at every level of the ladder. Two tests check that, scored by rules fixed before either one runs.

Test 1 · order effect

Classify, then replay. Replay, then classify.

Arm A labels each bypass with no replay result in view, then replays it. Arm B replays first, then labels with the outcome in view. Each arm's classifier never sees the other arm's labels.

Reads: a label that moves between arms was hindsight, not classification. Arm A's agreement with replay is the classifier's real accuracy; arm B's extra agreement is how much the outcome bent the call.

Test 2 · fractal invariance

One case, three levels, one primitive?

Classify each case on its own at the atom, the molecule and the organism, with no level able to see another's label.

Reads: where the primitive changes with the level, the structure is not self-similar there. The write-lock finding predicts at least one such break: a primitive that exists only at the protocol layer.

ScoreRule, fixed in advance
AccuracyArm A labels that match the replay verdict, over cases replay settles
Hindsight shiftCases whose label differs between arm A and arm B, over all cases
Level disagreementCases whose primitive differs between any two levels, over all cases
ClassifiersA local classifier first; TypeSafe as a third classifier only after the key and egress decision. Each scored separately, never pooled.

Limits

Three blind spots, stated

  • Silent wrong passes. A gate that let something wrong through, never reverted, leaves no trace. The shadow eval's 7,208 unrevealed commits are the upper bound, not a pass count.
  • Gates outside the hook and CI. Skills, agents and manual gauntlets that judge work are not atoms here yet.
  • Templates are read from invocation shape. Two checks called the same way may defend different primitives; the split of the check bucket is where that shows first.
