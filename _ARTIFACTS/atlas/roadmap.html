How this room is built, and what it does not show

Sequenced jobs come from scripts/backlog_graph.py --json --debt (backlog rows plus GitHub debt issues), enriched with each row's priority, door, ruin, route and issue link from _QUEUE/induced-backlog.jsonl, and priced by scripts/risk_underwriter.py. Priority is copied from the row; a row with none shows as unranked, never guessed.

Risk rules: Concave = one-way door, ruin high or medium, or a SPECIALTY / UNINSURABLE premium. Convex = the eight jobs with the most downstream dependents. Posterior = each Kintsugi class from the Project ledger, with its guard count. Anterior = jobs the tool-cluster map lists as having no tool. Parabolic = builds made against the PARKED hold. Orthogonal = words shared by four or more jobs. Owners are a role, not a person assigned by this script.

HUD integration: NOW, each job links to the field HUD (arcs.care/hud). NEXT: the HUD takes a job id and draws its route (WORLD.md THE HUD: terrain, route, time); today src/app/hud reads no query parameter, so that seam is not built.

Not shown: calendar dates and durations (most rows carry none; risk_underwriter prints UNKNOWN rather than guess), and scenarios or premortems, which are written by hand. Reading-room cache slices stay as graded; this room does not regrade. Em-dashes in source text display as hyphens here; the ledgers are unchanged.
