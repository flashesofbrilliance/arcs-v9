A few thousand commits of building this way. Merges go through a script that pins the exact commit being merged and refuses if any check is pending or failing. It has refused me twice when a branch moved under me. Pre-commit gates block a model name typed by hand. Pre-commit gates block a file moved while something still points to the old path. Pre-commit gates block a page whose text wraps badly at some screen width. Every merge ends with a decision receipt, and the ledger refuses edits; a correction is a new row. Whether the receipts make the calls better over time is not yet known; scoring stays off until enough outcomes close.
