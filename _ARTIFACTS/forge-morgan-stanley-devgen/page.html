The interesting part of an honest résumé is what it leaves out. These could not clear the evidence bar, or the posting asks for them and the record does not support them. They were cut, or never written, and moved to a defend-or-drop list.

✕
“60% decision-noise reduction · 3 to 5x time-to-insight”
Self-measured on my own platform with no external check. The softest numbers, so the first to go.
✕
A RAG pipeline or vector search claim
The posting names RAG. ARCS does structured context assembly from prior decision receipts, not vector retrieval. Written as what it is; not stretched to the keyword.
✕
A vendor AI gateway or cloud-provider claim
The posting lists Azure OpenAI, Bedrock, Vertex. The record is Claude API direct plus Vercel and Supabase. Nothing else is named.
✕
A second MIT certificate and a product-strategy credential
Only the one verified MIT xPRO course stays. The rest is held until it is linkable.
