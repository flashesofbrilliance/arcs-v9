The proof that it is hyperstition, not hindsight

The strange loop — the claim on trial

The films are not an outside observer's take. Film 1 says it plainly: "the very source material for this explainer, it was built using this exact ARCS framework … a real audit from the process of building the script." And all seven were generated by NotebookLM reading the ARCS corpus. So the loop closes — but note what that alone proves:

corpus → describes itself → vision film (Ethereal) → eight months → code + canon + 247 receipts → re-enters the corpus →

The honest reading first: films generated FROM the corpus matching a product built from the same corpus is exactly what the common-cause null predicts — the loop closing proves the corpus is consistent with itself. The hyperstition claim needs one more arrow: that a film was consulted mid-build, and no dated receipt of that exists anywhere in this family. So the finding is filed at its earned tier: the corpus described itself twice, eight months apart, and the second description ran — candidate hyperstition, causation unproven. Two things would settle it: the miss column below, and one dated commit, ADR, or session note citing a film before the feature it names. The search for that receipt has now been run (2026-08-28: git log --all --grep on every film title + NotebookLM across all branches, plus a full-text sweep of decisions, state, archives, and memory — method banked in dated-receipt-search.md): zero hits. Every film-citing commit is from the atlas session itself. The causal arrow is not merely unproven — it is searched-and-not-found. The common-cause null stands, and the claim this page keeps is exactly the one on the stamp below.
