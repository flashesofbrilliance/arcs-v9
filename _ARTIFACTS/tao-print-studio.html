ARCS · Tao print studioReproducible from proverb, recipe and seed. Not an edition.

Pull the Möbius until the ink gives out

One mold, printed again and again in flat inks. Set the proverb, the palette and the type, then wear the plates down with fidelity. Fidelity is a declared setting here, not a measurement.

    Pixel mosaic rasterizes the print, so it uses a system typeface and Copy SVG still copies the vector print. Studio prints repeat exactly inside the studio. The PNG exporter in the repo uses a different random stream, so its output matches the recipe, not the pixels.

    Style

    Each preset takes the form of an artist's approach: hand-lettered marker, splatter and Ben-Day dots, tile mosaic. No existing artwork is copied.
