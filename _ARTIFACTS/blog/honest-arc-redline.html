The RL disclaimerE1 · claims-skeptic
Say precisely what RL requires: a reward model, a weight update, a policy gradientthe RL story would need here: a parameter update on the model, computed from a reward signal, moving a policy.

Why: a reward model is RLHF-specific and a policy gradient is one RL family — stating them as RL's definition was loose. Tightened so the honesty spine is itself precise.

Product claim #2E2 · pathogen · S9
The compass returns a bearing, not a command. It says True North, never "you should." The word choice is constitutional. That framing is real and it renders, but it is a frame around the answer, not a guard on the answer's words. The system does not forbid "you should" — bearing-not-command lives in the label and the copy today, not in an enforced rule on the text.

Why: the same false-claim disease as S1, one sentence over in the same source doc. The code actually demands a direct, actionable sentence. Kept the honest half, cut the enforcement claim.

The "weights" payoffE1–E2 · BAR + Loki · S2
The weights are real. Those artifacts are the literal weights this ascent wrote to. The exemplars are a replay buffer. gains are real. They are the weights, in the analogy's terms, and the analogy stops at the arithmetic: you cannot average two files or take a step of defined size.

Why: "literal weights" / "replay buffer" negated the essay's own "it's an analogy" hedge — borrowed rigor in the climactic line, the exact house-rule violation the piece condemns.

The bitter-lesson counterE1 · BAR + cold-reader · S4
You cannot scale your way to it. You can only ask. ahead of asking — with no prior trace and a moving target, the first signal has to come from the person.

Why: the absolute "you can only ask" was self-contradicted (the essay had already called the trace a dataset). Narrowed to a claim that holds.

The actionable practiceE3–E4 · Court + falsifier · S16/S18
When you cut a direction, append it and a one-line reason to the same file. So make it cost nothing. No ceremony. It is not free — one decision and one line per cut, and it only pays off if you re-read the file before the next attempt. But that is a small, bounded cost against re-buying the same dead end.

Why: "costs nothing" was itself a small overclaim. Named the real (small) cost and the discipline it needs.

The spine (the big one)E4 · CRYSTAL falsifier · S19
The objective is never distilled into a proxy. There is no sample to train one on, so this differs from RLHF in kind. The accept/reject trace IS a sample — a proxy could be trained on it. So the real distinction is not "no representation," it is no substitution: the person stays the final judge. The edge is a legible record vs an opaque policy — a pragmatic difference, not a difference in kind.

Why: a cold stranger-AI proved the core premise false — and the false line had been introduced by an earlier fix. The headline claim shrank to the one it can defend. This is the drop you see on the trajectory chart.

New honest edges (added)E3–E4 · Court + Funhouse · S15/S17
A stale artifact is a proxy too. A skill file consulted instead of the person, after their taste has moved, is a stand-in — a legible one, but a stand-in.   The distinction is regime-bound: everything here holds at N=1, and claims nothing where amortization would pay.

Why: insertions, not cuts. The hardening didn't only remove overclaims; it added the limits the first draft was dancing around.
