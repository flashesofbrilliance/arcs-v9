One take per card, read in Zach’s voice: voice/01.mp3 to voice/08.mp3. Each card holds its take plus 0.8 s.

## 01

## 02

Each row is one line of JSON: a job, a state, what it waits on. Follow this one. Its job: clear false alarms from four doc gates so they can block.

## 03

First, a shape check. On a test copy, I marked it running with no name. The gate refused, and said why. Shape, not merit.

## 04

Then the graph. Edges come from depends on. Finished rows drop out. The rest sort into waves by their longest chain. This row’s one dependency is done, so it sits in wave zero. One row waits on it.

## 05

Eleven rows can start now. This is one. Its tools all resolve in the repo, so it is marked have. No model was called. The same file gives the same order.

## 06

Here the script stops. It orders. A person decides. A claim writes a name and a time, and the gate passes. Landed or withdrawn is a person’s call.

## 07

Now the thin spot. Two hundred twenty four of three hundred twenty active rows sit in wave zero, and one hundred seventy eight have no edge at all. So the order there is ranking, not dependency. The fix is in the rows: write depends on.

## 08

No model calls. Gates on shape. A person on every fate. And it names its own thin spot.
